# Forms, Tables, Dashboards, Reports

Operational interfaces are the core of ERP, portal, marketplace, supplier API pages, checkout, and future mobile workflows.

## Forms

Forms must prioritize completion:

- visible labels
- clear required/optional states
- inline validation
- accessible error messages
- stable field widths
- logical tab order
- clear submit/cancel/save behavior
- no distracting animation

RFQ, checkout, login, approval, accounting, inventory, portal account, and subscription forms must stay fast and predictable.

## Tables

Tables must prioritize scanning:

- real table semantics for tabular data
- sticky headers when useful
- sortable/filterable columns
- visible selected state
- row hover
- aligned numeric values
- readable density
- empty/loading/error states
- pagination or virtualization for large data

Avoid large animated reveals in tables.

## Dashboards

Dashboards should answer:

- What is the current state?
- What changed?
- What needs action?
- Where should the user go next?

Use metric cards, concise filters, drill-down paths, status summaries, and clear empty states.

## Charts and Reports

Charts and reports must prioritize trust:

- clear date range
- visible filters
- export controls
- accessible labels
- stable color semantics
- readable legends
- no misleading decoration

Financial, procurement, inventory, and performance reports should avoid decorative animation.
