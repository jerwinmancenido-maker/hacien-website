# Implementation Checklist

Use this for every HACIEN UI task.

1. Inspect existing product, page/screen/module, and nearby components.
2. Load shared foundations and the relevant product-specific guide.
3. Identify the active product: website, ERP, portal, marketplace, supplier API page, or mobile.
4. Follow the active product's framework conventions.
5. Use the active project's shared UI/component folder.
6. Apply core typography, color, spacing, radius, shadows, icons, and motion rules.
7. Evaluate React Bits with the five required questions.
8. Choose only purposeful animation.
9. Create reusable components instead of local one-offs.
10. Ensure mobile/responsive behavior.
11. Check semantic HTML or platform-native semantics.
12. Check keyboard, focus, contrast, reduced motion, and screen reader basics.
13. Check performance and bundle impact.
14. Verify forms, tables, dashboards, checkout, RFQ, approvals, and reports remain fast and clear.
15. Run available validation.
16. Summarize decisions, React Bits usage/skips, accessibility, performance, and remaining risks.
