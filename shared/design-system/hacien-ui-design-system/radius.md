# Border Radius

Radius should feel modern and enterprise-grade without becoming playful.

## Shared Scale

Recommended radius roles:

- 4px: compact controls, table cells, tags
- 6px: inputs, small buttons, compact cards
- 8px: standard cards, panels, modals
- 12px: prominent website cards or CTA panels
- 999px: pills, badges, circular controls

## Rules

- Use 8px or less for most operational UI.
- Use larger radius sparingly for website storytelling or hero CTA elements.
- Keep radius consistent within a screen.
- Do not mix many radius values in one view.
- Do not use rounded cards as decoration when structure does not require a card.
