# Marketplace Guidelines

Marketplace and product checkout should prioritize product discovery, software subscriptions, checkout clarity, license/subscription management, supplier API readiness, and account-based purchasing.

## Goals

- Make products easy to discover and compare.
- Make pricing, license terms, subscription state, and procurement conditions understandable.
- Keep checkout trustworthy and low-friction.
- Support supplier API product data without visual inconsistency.

## Product Discovery

Use clear category hierarchy, search, filters, product cards, comparison states, availability/status labels, and RFQ or checkout actions.

## Checkout

Checkout must be direct, accessible, and stable:

- no distracting animation
- clear steps
- visible totals
- clear account/purchasing context
- explicit confirmation
- recoverable errors

## Supplier API Pages

Supplier-fed content must conform to HACIEN component and token standards. Do not let supplier data dictate visual style.

## Motion

Use restrained product-card hover, loading skeletons, and progress feedback. Avoid expressive marketing motion during checkout.
