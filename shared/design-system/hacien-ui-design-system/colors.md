# Colors

HACIEN color should signal trust, technical clarity, and enterprise reliability.

## Core Palette Guidance

Use HACIEN navy and blue as anchors, balanced with white, slate, and neutral surfaces.

Recommended semantic roles:

- navy: headers, strong CTA bands, trusted foundation
- blue: primary actions, links, active states, procurement flow emphasis
- slate: text, borders, dashboard structure, metadata
- white/off-white: surfaces and readable content areas
- green: success only
- amber: warning only
- red: error/destructive only

## Rules

- Maintain readable contrast.
- Do not rely on color alone for status.
- Avoid one-note palettes.
- Avoid neon, gaming, or overly saturated gradients.
- Keep ERP status colors calmer than website CTA colors.
- Document any new color before reusing it.
