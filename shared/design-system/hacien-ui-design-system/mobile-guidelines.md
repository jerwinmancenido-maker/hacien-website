# Mobile Guidelines

Future mobile experiences should prioritize touch targets, simplified navigation, readable density, fast actions, accessible motion, and responsive cards/forms/tables.

## Touch

- Minimum comfortable touch targets.
- Clear spacing between actions.
- Avoid tiny icon-only controls without labels or tooltips.
- Keep destructive actions deliberate.

## Navigation

Simplify navigation by task:

- primary action visible
- common workflows reachable quickly
- deep module navigation avoided where possible
- breadcrumbs or back paths where needed

## Layout

Use responsive cards, stacked forms, simplified tables, summary-first screens, and progressive disclosure.

## Motion

Motion should be minimal and fast. Avoid long transitions, heavy gradients, and delayed content.

## Data Density

Mobile should preserve clarity over density. Use summaries, filters, and drill-downs instead of squeezing full desktop tables into narrow screens.
