# Prompts

## Planning

```text
Use the shared HACIEN Design System from shared/design-system/hacien-ui-design-system before planning this UI change. Load the core foundations and the relevant product guide. Do not assume website-only paths or framework conventions.
```

## Website

```text
Use the shared HACIEN Design System. Design this public website UI for trust, conversion, storytelling, SEO, RFQ flow, product browsing, and credibility. Use React Bits only when it improves hierarchy, usability, accessibility, performance, and reusability.
```

## ERP

```text
Use the shared HACIEN Design System. Design this ERP UI for speed, readability, data density, keyboard workflows, low cognitive load, and accessibility. Use only restrained micro-interactions.
```

## Portal

```text
Use the shared HACIEN Design System. Design this customer portal UI for self-service account management, quotations, orders, invoices, subscriptions, support tickets, and renewals.
```

## Marketplace

```text
Use the shared HACIEN Design System. Design this marketplace or checkout UI for product discovery, subscription clarity, account-based purchasing, supplier API readiness, and safe checkout completion.
```

## Review

```text
Review this HACIEN UI against the shared design system. Prioritize product-fit, consistency, accessibility, performance, React Bits misuse, over-animation, component reuse, and mobile behavior.
```
