# Customer Portal Guidelines

The customer portal should prioritize self-service, account management, quotations, orders, invoices, subscriptions, support tickets, and renewals.

## Goals

- Help customers find account information quickly.
- Make quotation/order/invoice status clear.
- Support renewals and support without confusion.
- Feel connected to HACIEN's public website and ERP.

## Layout

Use account-first navigation, clear status cards, simple lists, readable documents, and obvious support paths.

## Motion

Use restrained motion:

- loading states
- status transitions
- confirmation feedback
- empty states

Avoid marketing animations that reduce clarity.

## Components

Prioritize:

- account summary
- quotation list/detail
- order tracking
- invoice/payment status
- subscription status
- ticket creation/status
- renewal actions
