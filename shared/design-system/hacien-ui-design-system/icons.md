# Icons

Icons should improve recognition and scanability.

## Style

Use a consistent outline icon style unless a product-specific component requires otherwise. Icons should feel precise, calm, and enterprise-grade.

## Rules

- Pair unfamiliar icons with labels or tooltips.
- Use icons in toolbars and compact controls where they improve speed.
- Do not use decorative icon clutter.
- Keep icon size consistent within a component.
- Use status icons with text, not color alone.
- Ensure icon-only buttons have accessible names.

## Common Icon Uses

- navigation
- actions
- status
- filters
- search
- sort
- export/import
- approvals
- warnings/errors
- empty states

## Mobile

Mobile icons must support touch targets and should not replace critical labels unless the pattern is obvious.
