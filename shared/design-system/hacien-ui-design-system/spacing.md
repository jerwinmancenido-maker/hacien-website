# Spacing

Spacing should create rhythm and predictability across products.

## Shared Rules

- Use consistent increments rather than arbitrary values.
- Keep spacing stable between related controls.
- Use more whitespace for public storytelling pages.
- Use denser spacing for ERP, portal, reports, tables, checkout, and admin workflows.
- Preserve touch target spacing on mobile.

## Suggested Scale

Use a 4px-based rhythm:

- 4: tight internal spacing
- 8: compact control spacing
- 12: small groups
- 16: standard groups
- 24: section/card spacing
- 32: major layout spacing
- 48+: website storytelling sections

## Layout Density

Website:

- generous hero and section spacing
- clear CTA spacing
- breathing room for trust and narrative

ERP/Portal/Marketplace:

- compact panels
- predictable gutters
- stable form rows
- efficient table density
- no oversized marketing gaps
