# Typography

Typography should support trust, scanability, and operational clarity.

## Shared Rules

- Use large display type only for true website heroes or major marketing moments.
- Use compact headings inside dashboards, cards, sidebars, reports, tables, forms, and modals.
- Keep body text readable with comfortable line height.
- Use concise labels and helper text.
- Do not use negative letter spacing.
- Do not scale font size directly with viewport width.
- Avoid all-caps for long text; reserve it for short labels or eyebrows.

## Suggested Scale

Use a consistent type scale even if token files are not implemented yet:

- display: public website heroes only
- h1: page or module title
- h2: section title
- h3: card/panel title
- body: paragraph and standard UI text
- small: helper text, metadata, table details
- label: form labels, badges, compact controls

## ERP Density

ERP typography should be smaller and denser than marketing pages, but never cramped. Tables and forms must remain readable during long work sessions.

## Mobile

Mobile type should preserve hierarchy without oversized headings that push actions below the fold.
