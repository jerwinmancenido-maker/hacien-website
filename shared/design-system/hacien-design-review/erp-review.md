# ERP Review

Evaluate whether the ERP UI helps users work faster and with fewer errors.

## Check

- Data density
- Workflow clarity
- Table usability
- Form efficiency
- Keyboard workflow
- Approval flow
- Dashboard readability
- Filters/search
- Bulk actions
- Status visibility
- Audit/history visibility
- Error prevention

## Questions

- Would this help operators complete work faster?
- Is the next action obvious?
- Can frequent users move efficiently?
- Are tables readable and actionable?
- Are forms optimized for speed and accuracy?
- Are approvals and destructive actions clear?

## Reject

Reject marketing-style hero layouts, expressive animation, hidden critical actions, poor keyboard workflows, and low-density dashboards that slow daily work.
