# Consistency Review

Compare the implementation against the shared HACIEN UI Design System.

## Check

- Buttons
- Cards
- Forms
- Tables
- Colors
- Typography
- Spacing
- Radius
- Shadows
- Icons
- Motion
- Dialogs/modals/drawers
- Notifications/toasts/alerts
- Badges/pills
- Navigation
- Sidebars/topbars
- Breadcrumbs
- Pagination
- Search and filters
- Empty states
- Loading states
- Charts and reports
- Destructive actions

## Questions

- Does this feel like HACIEN?
- Does it match adjacent screens or pages?
- Are new patterns justified?
- Are components reused where possible?
- Would a user recognize this as the same ecosystem as the website, ERP, and portal?

## Flag

Flag hardcoded styling, one-off component variants, duplicate interaction patterns, inconsistent spacing, and product-specific styling that should become shared.
