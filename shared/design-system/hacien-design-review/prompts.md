# Prompts

## Pull Request Review

```text
Use shared/design-system/hacien-design-review to review this UI implementation before merge. Compare it against the HACIEN UI Design System, inspect UX, visual hierarchy, accessibility, performance, React Bits usage, consistency, product-specific readiness, security-sensitive UI, and SEO where applicable. Provide scores and a production recommendation.
```

## Website Review

```text
Use HACIEN Design Review for this public website page. Focus on trust, conversion, RFQ flow, product discovery, SEO structure, storytelling, React Bits restraint, accessibility, performance, and HACIEN ecosystem consistency.
```

## ERP Review

```text
Use HACIEN Design Review for this ERP screen. Focus on speed, data density, keyboard workflow, table/form usability, dashboard readability, approval clarity, accessibility, performance, and restrained motion.
```

## Portal Review

```text
Use HACIEN Design Review for this customer portal screen. Focus on self-service account workflows, quotations, orders, invoices, subscriptions, support tickets, renewals, accessibility, security-sensitive UI, and consistency.
```

## Marketplace Review

```text
Use HACIEN Design Review for this marketplace or checkout flow. Focus on product discovery, comparison, checkout clarity, subscriptions/licenses, supplier API readiness, accessibility, performance, and security-sensitive UI.
```
