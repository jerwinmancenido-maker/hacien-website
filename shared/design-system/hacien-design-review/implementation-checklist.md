# Implementation Checklist

Use before approving UI work.

1. Identify product surface and user goal.
2. Compare against HACIEN UI Design System.
3. Review visual hierarchy.
4. Review UX and task completion.
5. Review UI consistency.
6. Review React Bits and motion.
7. Review accessibility.
8. Review performance.
9. Review product-specific readiness.
10. Review security-sensitive UI.
11. Review SEO when public/indexable.
12. Identify component duplication or maintainability issues.
13. Assign severity to issues.
14. Score categories.
15. Give production recommendation.
