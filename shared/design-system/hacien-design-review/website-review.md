# Website Review

Evaluate public website quality, trust, SEO-adjacent structure, and conversion.

## Check

- First viewport clarity
- Brand credibility
- Storytelling flow
- Heading hierarchy
- CTA placement
- RFQ path
- Product browsing
- Solution browsing
- Internal links
- Mobile polish
- Page speed impact
- React Bits restraint

## Questions

- Does this feel like a premium B2B IT procurement company?
- Can visitors quickly understand what HACIEN does?
- Is the page trustworthy without overclaiming?
- Is there a clear next action?
- Does animation support storytelling rather than distract?
