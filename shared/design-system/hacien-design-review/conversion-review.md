# Conversion Review

Use for public website and marketplace surfaces where customer action matters.

## Website Conversion

Evaluate:

- trust signals
- CTA visibility
- RFQ path
- product discovery
- solution discovery
- contact options
- credibility
- social/proof or documentation signals where available
- first viewport clarity

Ask: does the page encourage meaningful customer action?

## Marketplace Conversion

Evaluate:

- product comparison
- pricing/subscription clarity
- cart/checkout confidence
- account purchasing clarity
- renewal/license confidence

## Do Not Optimize For Clicks Alone

HACIEN conversion should build trust and qualified procurement action, not cheap urgency.
