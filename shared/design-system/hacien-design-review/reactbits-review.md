# React Bits Review

React Bits should enhance the experience, not dominate it.

## Required Questions

1. Does it improve usability?
2. Does it support hierarchy?
3. Does it preserve performance?
4. Does it respect accessibility?
5. Is it reusable?

## Check

- Was React Bits used where appropriate?
- Were reusable components used?
- Are animations purposeful?
- Is motion restrained in ERP?
- Is storytelling enhanced on the website?
- Are animations accessible?
- Is reduced motion respected?
- Are duplicate implementations avoided?

## Reject

- excessive motion
- decorative animation
- distracting interactions
- duplicate animation components
- route/module-local pasted animation code
- website-level animation inside ERP workflows
- animation that delays forms, checkout, login, RFQ, approvals, tables, or reports
