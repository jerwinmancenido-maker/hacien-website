# UI Review

Evaluate visual hierarchy, polish, and readability.

## Visual Hierarchy

Review:

- headlines
- typography scale
- section order
- CTA placement
- whitespace
- layout balance
- reading flow
- content grouping
- visual emphasis

Ask: can users immediately understand the screen or page?

## Visual Quality

Check:

- alignment
- spacing rhythm
- color balance
- text contrast
- radius consistency
- shadow/elevation restraint
- icon consistency
- responsive layout
- mobile first viewport

## Quality Bar

The UI should feel credible beside Linear, Stripe, Vercel, Notion, Clerk, and Raycast-level product experiences while remaining HACIEN-specific and procurement-aware.
