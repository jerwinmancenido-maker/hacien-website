# UX Review

Evaluate whether users can accomplish their goal efficiently.

## Check

- Navigation clarity
- User journey
- Cognitive load
- Number of clicks
- Discoverability
- Task completion
- Clear next step
- Error recovery
- Empty states
- Loading states
- Content clarity

## Questions

- Can users immediately understand what this surface is for?
- Can users complete the primary task without guessing?
- Are choices clear and limited enough?
- Does the interface explain what happens next?
- Is there unnecessary friction?
- Does the flow respect repeat users?

## Product Lens

Website UX should guide visitors toward trust, RFQ, contact, and product/solution discovery.

ERP UX should help operators complete work faster with fewer mistakes.

Portal UX should make self-service obvious.

Marketplace UX should make product discovery and checkout confidence high.
