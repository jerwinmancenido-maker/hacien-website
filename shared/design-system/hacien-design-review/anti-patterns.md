# Anti-Patterns

Flag these during review.

## UX

- unclear primary action
- too many choices
- hidden critical actions
- confusing navigation
- weak empty/error states
- unnecessary clicks

## UI

- inconsistent typography
- poor spacing
- weak hierarchy
- low contrast
- inconsistent buttons/cards/forms/tables
- excessive shadows/glow
- layout imbalance

## React Bits and Motion

- forced React Bits
- decorative animation
- duplicate animation wrappers
- distracting motion
- motion that delays work
- website motion inside ERP workflows

## Operational

- low-density ERP tables
- slow forms
- poor keyboard workflow
- unclear approval/destructive actions
- reports that look decorative instead of trustworthy

## Maintainability

- duplicated components
- route/module-local one-offs
- hardcoded design values
- unnecessary dependencies
- framework-specific assumptions in shared patterns
