# Performance Review

Review performance as part of product quality.

## Check

- Bundle size impact
- Unused dependencies
- Lazy loading
- Animation cost
- Large assets
- Image/video optimization
- Layout shift
- Hydration cost
- Table/filter/search responsiveness
- Lighthouse impact for website pages

## Questions

- Did the implementation add a dependency for a small effect?
- Are heavy animations lazy-loaded when non-critical?
- Are critical forms, checkout, RFQ, and ERP controls immediately usable?
- Does motion use transform/opacity where possible?
- Are large media files justified and optimized?

## Product Lens

Website performance affects trust, SEO, and conversion.

ERP and portal performance affects daily productivity and user confidence.
