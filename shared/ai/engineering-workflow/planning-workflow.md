# Planning Workflow

Phase 1 is planning. No coding.

## Required Steps

1. Classify the task.
2. Identify required skills.
3. Review architecture.
4. Review existing code.
5. Review design system if UI is involved.
6. Review dependencies and constraints.
7. Identify data flow, state flow, and external systems.
8. Identify accessibility, performance, security, compliance, SEO, and testing needs.
9. Produce an implementation plan.
10. List open questions and assumptions.

## Planning Deliverables

- Markdown plan
- Skill stack
- Architecture notes
- Data flow or sequence notes when relevant
- UI/component strategy when relevant
- Risks
- Open questions
- Test and review plan

## Rule

If architecture is unclear or cross-product impact is likely, plan first and ask only the minimum blocking questions.
