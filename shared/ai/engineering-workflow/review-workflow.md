# Review Workflow

Phase 3 is review.

## Required Reviews

Run the applicable reviews:

- HACIEN Design Review for UI work
- Accessibility Review
- Performance Review
- Security Review
- SEO Review for public website/indexable pages
- Testing Review
- Architecture Review for shared or cross-product changes
- Compliance Review for BIR PH/accounting/tax workflows

## Review Deliverables

- Review report
- Priority issues
- Test results
- Final score when using HACIEN Design Review
- Recommendation: ready, minor improvements, major revision, or reject

## Rule

If any high-priority review issue remains, do not recommend production merge.
