# Required Skills

This workflow coordinates skills. It does not duplicate them.

## Always Consider

- HACIEN UI Design System for UI work
- HACIEN Design Review before merge for UI work
- HACIEN Security for auth, permissions, sensitive data, checkout, APIs
- HACIEN Performance for public, ERP, portal, marketplace, API work
- HACIEN Accessibility for user-facing UI
- HACIEN Testing for production changes
- HACIEN Deployment for release work

## Product Skills

- Website: HACIEN Website Architecture
- ERP: HACIEN ERP Architecture
- Portal: HACIEN Customer Portal
- Marketplace: HACIEN Marketplace
- Supplier integrations: HACIEN Supplier API
- Compliance: HACIEN BIR PH Compliance

## Missing Skills

If a referenced skill does not exist yet, recommend creating it. Do not invent detailed rules in this workflow that should belong to that missing skill.
