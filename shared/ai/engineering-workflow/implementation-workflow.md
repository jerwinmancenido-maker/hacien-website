# Implementation Workflow

Phase 2 is implementation.

## Required Steps

1. Follow the approved architecture and plan.
2. Use shared components and shared patterns.
3. Follow the HACIEN UI Design System for UI work.
4. Reuse existing code and utilities.
5. Avoid duplication.
6. Keep changes scoped to the task.
7. Update documentation when behavior, architecture, or workflow changes.
8. Add tests according to risk and blast radius.
9. Preserve existing user work and unrelated changes.

## UI Work

Use the active project's framework conventions. Do not create project-specific rules that belong in shared design-system skills.

## API/Backend Work

Preserve contracts, validation, error handling, observability, security controls, and integration boundaries.

## Compliance Work

Use compliance-specific skills before changing financial, tax, invoice, receipt, or BIR PH-adjacent workflows.
