# Quality Gates

Every implementation should satisfy relevant gates before merge.

## Gates

- Architecture
- Design
- Accessibility
- Performance
- Security
- Testing
- Documentation
- Consistency
- React Bits usage
- Component reuse
- Maintainability
- Compliance when applicable
- SEO when public/indexable

## Failure Rule

If any required gate fails, recommend revision before merge.

## Evidence

Prefer concrete evidence:

- build output
- test output
- browser check
- accessibility notes
- performance observations
- review report
- code references
