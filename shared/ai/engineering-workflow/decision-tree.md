# Decision Tree

Use this routing model.

## Website Redesign

```text
User requests homepage/about/products redesign
-> Website task
-> Website Architecture
-> UI Design System
-> Planning
-> Implementation
-> Design Review
-> Accessibility
-> Performance
-> SEO
-> Production Readiness
```

## ERP Module

```text
User requests inventory/quotation/billing/report module
-> ERP task
-> ERP Architecture
-> Security
-> UI Design System if UI is involved
-> Planning
-> Implementation
-> Testing
-> Design Review if UI is involved
-> Accessibility
-> Performance
-> Production Readiness
```

## Supplier API Integration

```text
User requests supplier API integration
-> API Integration task
-> Supplier API
-> Marketplace if product/checkout impact exists
-> ERP Architecture if sync/back office impact exists
-> Security
-> Planning
-> Implementation
-> Testing
-> Deployment
```

## Checkout

```text
User requests checkout flow
-> Marketplace task
-> Marketplace
-> Security
-> UI Design System
-> Performance
-> Planning
-> Implementation
-> Testing
-> Design Review
-> Production Readiness
```
