# Anti-Patterns

HACIEN should never become:

- a generic ERP
- an accounting-first ERP
- a flashy portfolio
- a generic e-commerce website
- a marketplace without procurement workflows
- a collection of disconnected modules
- a product catalog with no sourcing/quotation logic
- an AI tool that invents business commitments

Avoid:

- unnecessary complexity
- duplicate workflows
- feature bloat
- disconnected customer and internal workflows
- generic reseller claims
- roadmap claims presented as current features
