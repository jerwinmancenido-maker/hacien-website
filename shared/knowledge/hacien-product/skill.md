# HACIEN Product Knowledge

Use this skill before planning, designing, architecting, writing content, or implementing HACIEN work.

This is the shared company and product handbook. It explains what HACIEN is, how the business works, what the platform is becoming, and which assumptions future AI agents must avoid.

## Core Rule

Do not default to generic ERP, generic e-commerce, generic IT reseller, or generic SaaS assumptions. Understand HACIEN first, then consult:

```text
Product Knowledge
-> Engineering Workflow
-> Architecture skills
-> UI Design System
-> Implementation
-> Design Review
```

## Roadmap Honesty

Clearly distinguish current capabilities from roadmap items. Do not claim future ERP, marketplace, supplier API, customer portal, or AI capabilities are already implemented unless verified in the active project.
