# Implementation Guidance

Future AI agents should use this skill before making business, architecture, UI, content, workflow, or product decisions.

## Required Sequence

```text
Read Product Knowledge
-> Consult Engineering Workflow
-> Consult relevant Architecture skill
-> Consult UI Design System if UI is involved
-> Implement
-> Run Design Review if UI is involved
```

## Guidance

- Preserve procurement-first assumptions.
- Distinguish roadmap from implemented capabilities.
- Use official terminology.
- Reuse connected platform concepts.
- Avoid generic ERP and e-commerce defaults.
- Ask whether the change supports requirement, canvass, quotation, approval, procurement, delivery, invoice, or support workflows.

## Documentation Rule

If future product decisions add new business rules, update this knowledge skill or recommend a new dedicated skill instead of burying the decision in implementation code.
