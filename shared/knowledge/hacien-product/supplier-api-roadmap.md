# Supplier API Roadmap

Supplier API integrations are roadmap capabilities unless verified in the active project.

## Future Integrations

- product synchronization
- pricing
- availability
- license provisioning
- renewals
- order status
- ERP synchronization

## Product Implications

Supplier API data should support HACIEN workflows, not dictate them. Product data, pricing, and availability still need HACIEN rules for display, customer commitment, RFQ, checkout, and procurement approval.

## Honesty Rule

Do not claim supplier API functionality is implemented unless the current codebase proves it.
